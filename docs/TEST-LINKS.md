## URL format

`https://bds6.github.io/qr-demo/equip-help.html?asset=ASSET&room=ROOM&id=UNIQUE-ID`

- `asset` controls the displayed equipment name and initial question.
- `room` controls the displayed location and conversation metadata.
- `id` identifies the physical item and keys the duplicate-message guard.

For production, each physical item should keep a stable ID. Fresh IDs are only useful while repeatedly testing automatic startup in the same browser session.
