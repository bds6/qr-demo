# Legacy proof of concept

These files predate the GitHub Pages prototype and are preserved for historical reference only.

- `qrcodehelpbot.html` is the early Social Intents 1.5 experiment that read `asset` and `room` parameters and attempted to open and submit the first message.
- `basic-test.html` is the basic 1.4 widget test without QR context.
- `social-intents-notes.rtf` contains a short note about the representative's 1.5 installation guidance.

Do not deploy these files. The canonical deployable page is `/equip-help.html` at the repository root.
